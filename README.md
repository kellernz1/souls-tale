# 🕯️ Souls Tale: Soulsborne Lore Reader

A minimalist, atmospheric web application designed for fans of *Dark Souls* and *Elden Ring* to explore the deep lore of iconic items. The experience is crafted to be slow, somber, and contemplative — mimicking the feeling of discovering a legendary artifact in a ruined world.

---

## 🌙 Overview

**Souls Tale** is more than just an inventory — it's a ritual.

Each item is presented within a dark, smoke-filled altar. Upon interaction, the world fades to black, the crackling of a bonfire rises, and the item's history is revealed sentence by sentence through a cinematic reading experience.

The project focuses heavily on atmosphere, immersion, and emotional pacing inspired by the Soulsborne universe.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/tale-of-the-item.git
cd tale-of-the-item
```

### 2. Organize Assets

Ensure all images and audio files are placed correctly inside the `assets/` directory.

Example:

```text
/assets
├── audio
│   ├── bonfire.mp3
│   ├── chime.mp3
│   └── you_died.mp3
├── images
│   ├── item-1.png
│   ├── item-2.png
│   └── background.jpg
```

### 3. Open the project

Simply open `index.html` in any modern web browser.

---

> ⚠️ **Important:**  
> Browser policies require user interaction before playing audio.  
> The player must click **"Enter the Vault"** to enable atmospheric sounds.
